# Cyber Tetris 🕹️⚡

Современная аркадная веб-версия классической игры **Тетрис** с неоновой киберпанк-стилистикой, звуковыми эффектами на базе Web Audio API и адаптивным управлением.

---

## ✨ Особенности

- **🎮 Полная механика Тетриса**:
  - Все 7 классических фигур (тетромино: I, J, L, O, S, T, Z)
  - 7-bag рандомизатор (гарантирует честное и сбалансированное выпадение фигур)
  - Система вращения SRS (Super Rotation System) с поддержкой wall-kicks (отскоков от стен и блоков)
  - Очередь следующих 3-х фигур (Next Queue)
  - Удержание фигуры (Hold Queue, клавиша `C` или `Shift`)
  - Теневая проекция падения (Ghost Piece)
  - Мгновенный сброс (Hard Drop) и ускоренный спуск (Soft Drop)
  - Повышение уровня сложности каждые 10 линий с ускорением падения

- **🎨 Неоновый киберпанк дизайн**:
  - Темная тема с эффектами размытия (glassmorphism)
  - Неоновые градиенты и свечение активных блоков
  - Взрывные частицы при сгорании линий и сбросе фигур
  - Тряска экрана (Screen Shake) при мощных ударах и линии TETRIS!
  - Всплывающие анимации набранных очков (`+800 TETRIS!`, `+300`)

- **🔊 Синтезатор звука (Web Audio API)**:
  - 100% чистый код без сторонних аудиофайлов (нулевая задержка, работает офлайн)
  - Звуки вращения, движения, приземления, хард-дропа, очистки линий, перехода на новый уровень и Game Over
  - Опциональная фоновая ретро-музыка в стиле 8-bit / Synthwave
  - Сохранение рекорда (High Score) в `localStorage`

- **📱 Управление**:
  - **Клавиатура**:
    - `←` `→` или `A` / `D` — перемещение
    - `↑` или `W` — поворот по часовой стрелке
    - `Z` — поворот против часовой стрелки
    - `↓` или `S` — мягкий спуск
    - `Пробел` — мгновенный сброс (Hard Drop)
    - `C` или `Shift` — удержание фигуры (Hold)
    - `P` или `Esc` — пауза
    - `R` — перезапуск
  - **Смартфоны / Планшеты**:
    - Экранный сенсорный геймпад
    - Жесты свайпов по игровому полю (свайп влево/вправо/вниз/вверх, тап для вращения)

---

## 🚀 Запуск игры

Вы можете запустить игру любым удобным способом:

1. **Просто открыть в браузере**:
   Дважды кликните по файлу `index.html` в папке `tetris-game`.

2. **Через локальный сервер**:
   ```bash
   node server.js
   ```
   И откройте в браузере: `http://localhost:8089/`
